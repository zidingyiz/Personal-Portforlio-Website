Field Tracking Robot

An autonomous field-tracking robot developed for ELEC 291, using inductive sensors to detect a hidden guide wire and respond to path commands.

DemoGitHub

Overview

Designed and implemented robot-side control logic for track following, intersection handling, motor balancing, and serial debugging.

Tech Stack

  • EFM8 microcontroller
  • Embedded C
  • ADC sensor processing
  • PWM motor control
  • UART serial debugging
  • CrossIDE firmware workflow

Implementation Notes

  • Used a three-inductor sensor system with real-time ADC readings to estimate the robot's position relative to the hidden guide wire.
  • Implemented PWM-based differential motor control through an H-bridge driver for forward, backward, left, and right movement.
  • Built autonomous path-following logic with intersection detection using the middle sensor.
  • Supported manual driving, autonomous tracking, predefined path execution, and mode switching through an IR remote command interface.
  • Added scan mode for field-strength data collection, UART logging, and offline sensor visualization.
  • Integrated Time-of-Flight distance sensing for obstacle or collision-related behavior.
