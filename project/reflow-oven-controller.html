Reflow Oven Controller

A group oven-control project that used the DE10-Lite FPGA development board, external circuit components, CV-8052 embedded logic, and finite-state control to measure, compute, display, and regulate oven temperature.

DemoGitHub

Overview

Designed and implemented a temperature measurement, control, and display system for an oven using FPGA-based embedded logic and external circuit hardware.

Tech Stack

  • DE10-Lite FPGA development board
  • 8051 assembly language
  • CV-8052 soft-core
  • SystemVerilog
  • Intel Quartus
  • ADC data acquisition

Implementation Notes

  • Designed and implemented a temperature measurement, control, and display system for an oven using the DE10-Lite FPGA development board and external circuit components.
  • Developed embedded control logic on the CV-8052 soft-core in 8051 assembly language, including ADC data acquisition, temperature computation, and display handling.
  • Implemented a finite-state machine to control oven operating states, including idle, heating, and steady state, based on temperature thresholds.
  • Deployed the system by synthesizing and loading the CV-8052 soft-core in SystemVerilog onto the DE10-Lite using Intel Quartus.
