Reflow Oven Controller

A five-person oven control project using the DE10-Lite FPGA development board, external circuit components, and embedded control logic.

DemoGitHub

Overview

Designed and implemented a temperature measurement, control, and display system for an oven using FPGA and external circuit hardware.

Tech Stack

  • DE10-Lite FPGA development board
  • 8051 assembly language
  • CV-8052 soft-core
  • SystemVerilog
  • Intel Quartus
  • ADC data acquisition

Implementation Notes

Developed embedded control logic for ADC acquisition, temperature computation, display handling, and finite-state machine control across idle, heating, and steady-state modes.
