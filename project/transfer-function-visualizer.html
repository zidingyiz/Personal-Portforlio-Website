Transfer Function Visualizer

This project is currently ongoing. It is planned as an interactive tool for visualizing transfer functions, pole-zero behavior, Bode plots, and basic circuit response.

OngoingGitHub

Overview

Development is still in progress. The goal is to build a clear visual bridge between control theory, signal behavior, and circuit examples.

Planned Features

  • Transfer function input
  • Pole-zero map
  • Bode magnitude and phase plots
  • Filter type recognition
  • Example RC/RLC circuit responses

Roadmap

Ongoing work will focus on prototyping the plotting logic first, then packaging the visualizer into a lightweight web interface once the core behavior is stable.
