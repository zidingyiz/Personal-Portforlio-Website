Transfer Function Visualizer

An ongoing personal project developing a Python-based transfer function visualizer with filter-mode selection, custom transfer-function input, and Bode plot generation.

OngoingGitHub

Overview

Developing an interactive tool that helps connect filter parameters, transfer functions, and plotted frequency response through a clearer visual workflow.

Planned Features

  • Filter-mode selection for low-pass, high-pass, and band-pass filters
  • Custom transfer-function input
  • Bode magnitude and phase plot generation
  • Parameter input, error checking, and automated plot output
  • Planned reference circuit diagrams and transfer-function explanations

Roadmap

Built an initial Tkinter prototype using NumPy and Matplotlib to model filter responses based on cutoff frequency, gain, and termination frequency. Ongoing work focuses on packaging the tool into a web-based version and documenting the project through GitHub.
