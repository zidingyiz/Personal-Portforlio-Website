# Personal Portfolio Website

A personal portfolio website for Qijun Zhou, built as a lightweight static site for showcasing engineering projects, experience, coursework, and personal interests.

## Live Site

This portfolio is deployed with Netlify:

https://kenzhou.netlify.app/

## Pages

- `index.html` - Homepage with work, projects, and contact information
- `experience.html` - Work and volunteer experience details
- `courses.html` - Academic course record with searchable course cards
- `interests.html` - Music and soccer interests page
- `project/field-tracking-robot.html` - Field tracking robot project detail page
- `project/reflow-oven-controller.html` - Reflow oven controller project detail page
- `project/research-paper.html` - Published research paper detail page
- `project/transfer-function-visualizer.html` - Transfer function visualizer placeholder page

## Tech Stack

- HTML
- CSS
- JavaScript
- Netlify
